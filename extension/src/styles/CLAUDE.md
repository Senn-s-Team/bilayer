成员清单
tokens.css: 设计令牌层，primitives（灰阶/深色中性阶/品牌蓝/琥珀/绿/红/紫、字体族 --bl-font-sans（-apple-system/BlinkMacSystemFont/system-ui 系统栈，不含 Helvetica）/--bl-font-mono、间距、扁平圆角阶梯 --bl-radius-2xs 2px/-xs 3px/-sm 4px/-md 6px/-lg 8px/-xl 10px（无胶囊档）与三枚角色别名 --radius-tag=2xs（徽标/标签/进度条/字幕行）、--radius-control=sm（按钮/输入/分段/列表行）、--radius-surface=md（面板/卡片/浮层；窗口级外壳取 --bl-radius-xl）、字号行高字重（含展示级 --bl-font-2xl/--bl-font-3xl）、控件高度与图标尺寸、时长与缓动 --bl-duration-*/--bl-ease-standard(0.32,0.72,0,1)/spring/out-expo/inout-quint/springy）加 semantic（--bg/--fg、--surface/--surface-fg、--border/-strong/-hover、--accent/--accent-fg/-soft/-line/-faint/-badge/-solid、--success/--warning/--danger 及 -fg、--focus-ring、唯一浮层阴影 --shadow-popover、不透明窗口级表面 --sidebar-bg/--header-bg、内凹槽底色 --groove、扁平深色屏幕 --stage-bg/--stage-fg/--stage-label-fg/--stage-line-bg/--stage-line-shadow）；:root 是浅色唯一事实来源，`@media (prefers-color-scheme: dark)` 用同一组变量名覆盖（深色靠表面色深浅 + 1px 发丝边区分层级），`color-scheme` 只在 :root 声明一次。扁平契约：一层不透明表面 + 1px 发丝外框，无磨砂/模糊、无光泽（无 sheen/tray/inset 高光）、无胶囊圆角，只有真正浮起的弹层投 --shadow-popover 单层收敛阴影；历史玻璃令牌（双层壳外托/内芯与顶部高光、斜向高光、内凹槽发丝环与内阴影、漫射多层阴影与发光阴影、胶囊与同心圆角、壳宽与多余阴影档）已在本轮全部删除，令牌层只保留扁平契约所需项
controls.css: 控件唯一基线——checkbox 开关（.toggle/.toggle-track）、range（::-webkit-slider-* 与 ::-moz-range-* 成对）、color（.color-control/.color-picker-row）、select（自绘箭头取 --select-arrow）、text/number/url/password/search/textarea、数字复合控件 .number-control、取色复合控件，以及按钮三档（实心 .ai-button-primary；描边 .ai-button/.icon-button/.preset-pill/.master-tool-btn；无边框 .ai-button-quiet/.inline-link），每档含 hover/active/focus-visible/disabled 四态（disabled 为 opacity .5）与同一枚 focus ring；各页冻结的等价类名（.btn/.btn-outline/.btn-quiet/.btn-primary/.btn-accent/.preset-chip/.icon-btn/.quiet-button/.payload-format）作为同一档成员列出，页面样式表不得为这些名字重写几何。扁平质感在这一层统一：文本类控件与复合控件用 --groove 底面 + 1px --border 发丝边 + --radius-control(4px)，开关轨道/滑杆轨道/滑块与开关拇指是无光泽的实心填充（半径取 --bl-radius-2xs(2px)，无内阴影、无顶部高光），hover 只提一档描边或底色（按钮抬升 .5px）、active 缩到 .98，全部缓动取自 --bl-ease-*；`.preset-pill/.preset-chip` 是冻结类名，扁平化后不再是胶囊，与其余按钮同为 4px 圆角；文件末尾的 prefers-reduced-motion 兜底块把三页的过渡与动画一并压到 .01ms（onboarding.css/diagnostics.css 因此无需各自声明）

令牌只声明自定义属性、不产生选择器副作用；控件外观只在这一层定义一次，组件样式表（settings.css、settings-ai.css、onboarding.css、diagnostics.css）只写布局与变体覆盖，不得再出现同名控件的第二条基线，页面里出现同档控件时把类名加进本层对应档位的选择器清单（HTML 类名冻结、无法改动时，页面侧只落一次几何并注明所属档位）。`--bl-*` 是尺度与色阶（含字体族与展示级字号），语义令牌按角色命名并只引用 primitives；明暗差异一律落在语义层，组件规则里不得出现裸色值。圆角只走扁平阶梯与三枚角色别名，长条状元素（轨道、进度条、状态条、徽标）一律不得使用 50%/胶囊圆角。仅有几处刻意固定的取值：预览画板（--stage-*）是「屏幕」语义，明暗两态都保持深色（平面深色底 + 1px 发丝外框，不反光）；第二字幕的角色标记（--role-secondary/--role-secondary-ring）沿用维护者给定的紫色而不是品牌琥珀；诊断页的语法着色借用语义令牌（键/数值=accent 家族、字符串=warning、布尔=success、参考线=border-strong）而不新增一整套 code 调色板。`--select-arrow` 是按钮/下拉自绘箭头的数据 URI，明暗两态各一条，只有颜色不同。

接入方式：settings.html 与 onboarding.html 在本页组件样式表之前以 `<link>` 依次加载 tokens.css 与 controls.css；诊断控制器在 settings 第五页签内挂载，复用该窗口的共享层。本页 CSS 只消费本层令牌与控件基线，不再声明第二套调色板或第二套明暗分支。
